Dead ends — disproven, do not re-chase

  • Debug-cheat spawn (“Spawn Follow/RedBall/Still/Fight Dude”) — creates transient markers the manager deletes each frame; never renders a body.
  • Hijack an NPC by position — actor+0x800 is the ghost/teleport saved-position slot, not the live transform.
  • Set-transform on the player object — player+0x20 is floats, not a component. (Crash was isolated; game survived.)
  • Set-transform on an AI actor — actor+0x20 is a small integer (0x11896), not a component.
  • Near-player component scan — only a constant-data component (vt=0x142397720) found; no transform.
  • Copying AC Unity's co-op into BF — different engine generation (AnvilNext 2.0 vs AnvilNext) and architecture (x64 vs x86); the right oracle is BF's own MP exe.
